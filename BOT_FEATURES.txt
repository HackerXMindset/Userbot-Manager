TELEGRAM USERBOT MANAGER - FEATURE LIST

CORE FUNCTIONALITY
- Monitors source chats (channels, groups, DMs) for Solana token addresses
- Forwards token calls to target groups automatically
- Multi-userbot management
- Multi-admin support

USERBOT MANAGEMENT
- Add userbots via phone/code/2FA login
- Check individual userbot connection status
- Delete userbots with confirmation
- View userbot details and assignments
- Health check for all userbots
- Refresh source monitoring for all userbots

GROUPS MANAGEMENT
- Add target groups for token forwarding
- View all configured groups
- Delete groups
- Assign userbots to specific groups
- Set daily/time-based forwarding schedules
- Configure notification channels per group

SOURCES MANAGEMENT
- Monitor Telegram channels for tokens
- Monitor private/public groups
- Monitor direct messages for tokens
- Configure routing rules (which sources route to which groups)
- Control user permissions for triggering forwards
- View source monitoring statistics

ALERTS & TRACKING
- Set gain multiplier thresholds (5x, 10x, 20x, etc.)
- Set stop-loss drop percentages
- Monitor market cap changes for detected tokens
- View top performing tokens
- Auto-stop tracking on major drops
- Send alerts to configured channels

SCHEDULING SYSTEM
- Set active days (Mon-Sun)
- Configure start/end times
- Set maximum calls per time window
- Add, edit, delete schedules per group

ADMINISTRATION
- Multiple administrator support
- Admin-only access control
- System status monitoring
- Source configuration updates
- Button-based menu navigation

DATA MANAGEMENT
- PostgreSQL database with Supabase integration
- Event logging for all system activities
- Token database storage and management
- Performance and usage statistics
- Cleanup of old/inactive data

SECURITY
- Secure Telegram session handling
- User permission validation before forwarding
- Connection health monitoring
- Two-factor authentication support
- Telegram API rate limiting compliance

INTEGRATIONS
- DexScreener for token market data
- Solana token address detection
- Telegram Bot and Client APIs
- Supabase cloud database
