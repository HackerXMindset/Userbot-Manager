## Comprehensive Architecture Document: Telegram Userbot Manager System

### Overview
This repository contains two distinct but complementary systems for managing Telegram bots in the context of Solana token analysis and monitoring:

1. **Python App Package** (`/app`): A comprehensive Telegram bot management system with userbot orchestration, monitoring, and forwarding capabilities
2. **Rust Telegram Token Bot** (`/telegram_token_bot`): A high-performance Solana token analysis bot

Both systems are independent but share a common domain focus on Telegram bot integration and Solana token processing.

### Python App Package Architecture

#### Core Components
The Python application follows a modular, service-oriented architecture:

1. **System Orchestrator** (`app/runner.py`):
   - Main entry point that initializes and manages all system components
   - Coordinates startup/shutdown of services
   - Handles graceful shutdown with signal handlers

2. **Management Bot** (`app/management_bot.py`):
   - Interactive Telegram bot for admin control
   - Provides UI with inline keyboards and FSM states
   - Handles commands for bot management, scheduling, alerts, monitoring

3. **Userbot Manager** (`app/userbot/manager.py`):
   - Manages multiple concurrent userbot workers
   - Handles worker lifecycle (start/stop/restart)
   - Provides health checks and status monitoring

4. **Service Layer**:
   - **Call Dispatcher** (`app/services/call_dispatcher.py`): Processes job queues and delegates to userbots
   - **DexScreener Service** (`app/dex.py`): Integration with market data APIs
   - **Event Router** (`app/events.py`): Routes and processes incoming events

5. **Database Layer** (`app/db.py`):
   - PostgreSQL/SUPABASE integration with connection pooling
   - Async database operations

6. **Data Models** (`app/models/`):
   - `BotModel`: Userbot session and status management
   - `GroupModel`: Group configuration and scheduling
   - `TokenModel`: Token tracking and monitoring
   - `EventModel`: Event processing and routing
   - Additional models for notifications, templates, etc.

7. **UI Layer** (`app/ui/`):
   - Interactive keyboards and FSM state management
   - Handler modules for different UI sections

#### Data Flow in Python System
1. **Initialization**: System manager initializes all components in dependency order
2. **Userbot Operations**: 
   - Userbots connect to Telegram via Telethon
   - Monitor configured groups/channels/users
   - Detect Solana addresses using regex patterns
   - Process market data via DexScreener API
   - Store events in database
3. **Management Interface**:
   - Admin commands processed via FSM
   - Database queries update configuration
   - Real-time updates to worker configurations
4. **Call Forwarding**:
   - Source monitoring detects tokens
   - Event router processes and validates
   - Call dispatcher selects appropriate userbot
   - Messages forwarded to target channels

### Rust Telegram Token Bot Architecture

#### Core Components
The Rust application uses an asynchronous, concurrent design:

1. **Entry Point** (`src/main.rs`):
   - Environment variable loading
   - API client initialization
   - Telegram bot startup using teloxide

2. **Bot Handler** (`src/bot.rs`):
   - Message processing and contract address detection
   - Response formatting with HTML markup
   - Error handling and timing metrics

3. **API Client** (`src/api.rs`):
   - Concurrent API calls to multiple services (Helius, DexScreener, pump.fun, Jupiter)
   - Connection pooling and rate limiting
   - Timeout management

4. **Data Types** (`src/types.rs`):
   - Strongly-typed data structures for all token information
   - Comprehensive token metadata, holders, market data

#### Data Flow in Rust System
1. **Initialization**: Load environment variables, initialize API client
2. **Message Processing**: Detect contract addresses in incoming messages
3. **API Integration**: Concurrently query multiple services for token data
4. **Response Formatting**: Compile comprehensive token information with HTML formatting
5. **Output**: Send formatted response back to Telegram user
